定义一个镜像怎么构建
- `RUN`：**构建镜像时执行命令**
- `CMD`：**容器启动时执行命令**

```dockerfile
FROM python:3.11
WORKDIR /app
COPY . .
RUN pip install -r requirements.txt
CMD ["python", "app.py"]
```
用于：docker build -t <镜像名> <镜像位置>
