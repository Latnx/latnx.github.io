# 1️⃣ Mutex（互斥锁） {#h-fe6ab9a933c5b67b}

用于保护共享资源。
常用方法：
- `Lock()`
- `Unlock()`
- `TryLock()`（Go 1.18+）
### 示例 {#h-101288fe245e90db}

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var mu sync.Mutex
	count := 0

	mu.Lock()
	count++
	mu.Unlock()

	fmt.Println(count)
}
```

# 2️⃣ RWMutex（读写锁） {#h-5a650f8f8e697be7}

读写分离，提高并发性能。

常用方法：
- `Lock()` / `Unlock()` （写锁）
- `RLock()` / `RUnlock()` （读锁）
### ✅ 最小示例 {#h-11dda59adcc1c649}

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var mu sync.RWMutex
	data := 10

	mu.RLock()
	fmt.Println(data)
	mu.RUnlock()
}
```

# 3️⃣ WaitGroup（等待协程完成） {#h-814212de1b834847}

用于等待多个 goroutine 执行完成。
常用方法：
- `Add(n)`
- `Done()`
- `Wait()`
### ✅ 示例 {#h-6400b651f55bc80b}
```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var wg sync.WaitGroup

	wg.Add(1)
	go func() {
		defer wg.Done()
		fmt.Println("hello")
	}()

	wg.Wait()
}
```

# 4️⃣ Once（只执行一次） {#h-0bb5a9442e1f4cd4}

确保某段代码只执行一次。
常用方法：
- `Do(func())`
### 示例 {#h-7c51ff6b826156dd}
```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var once sync.Once

	once.Do(func() {
		fmt.Println("only once")
	})
}
```

# 5️⃣ Cond（条件变量） {#h-f8f65edc4783722b}

用于通知等待的 goroutine。

常用方法：

- `Wait()`    
- `Signal()`    
- `Broadcast()`    
### 示例 {#h-5130340a3a968ed5}

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	mu := sync.Mutex{}
	cond := sync.NewCond(&mu)

	go func() {
		mu.Lock()
		cond.Wait()
		fmt.Println("received signal")
		mu.Unlock()
	}()

	mu.Lock()
	cond.Signal()
	mu.Unlock()
}
```

# 6️⃣ Map（并发安全 map） {#h-7fac9dc5dade59bb}

线程安全的 map。

常用方法：
- `Store(key, value)`
- `Load(key)`
- `Delete(key)`
- `Range(func)`

### 示例 {#h-ea073b0bc949b3d6}

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	var m sync.Map

	m.Store("a", 1)
	v, _ := m.Load("a")
	fmt.Println(v)
}
```

# 7️⃣ Pool（对象池） {#h-7ca8505ef25b85f0}

用于减少频繁分配对象带来的 GC 压力。
常用方法：
- `Get()`
- `Put(x)`

### 示例 {#h-73ee0637da8c248b}

```go
package main

import (
	"fmt"
	"sync"
)

func main() {
	pool := sync.Pool{
		New: func() any {
			return "new object"
		},
	}

	obj := pool.Get()
	fmt.Println(obj)
	pool.Put(obj)
}
```
